# Web de la política de privacidad de Lumijar

Archivos (todos van en la raíz del repositorio):

| Archivo | Para qué |
|---|---|
| `index.html` | La política de privacidad |
| `app-ads.txt` | Autoriza a Google AdMob a vender anuncios de Lumijar (cuenta pub-8595782334170844) |
| `icono.png`, `favicon.png`, `apple-touch-icon.png` | Icono de Lumijar |
| `fuentes/` | Tipografía Fredoka alojada aquí (licencia OFL), para no cargar nada de terceros |
| `.nojekyll` | Indica a GitHub Pages que publique los archivos tal cual |

Antes de publicar, sustituye en `index.html` los campos resaltados en amarillo:
`[FECHA]`, `[NOMBRE Y APELLIDOS]`, `[NIF]`, `[DIRECCIÓN]` y `[CORREO DE CONTACTO]`.

La guía paso a paso para publicarla con GitHub Pages está en la conversación con Claude.
